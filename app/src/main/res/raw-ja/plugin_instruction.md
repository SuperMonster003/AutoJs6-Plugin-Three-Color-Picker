3-Color Picker は画面のカラーピッカーです. ドラッグできるターゲットリングとリアルタイムの拡大鏡で画面上の任意のピクセルを選び, 色と座標を HEX または RGB 形式でコピーできます. ランチャーから単独で使えるほか, AutoJs6 のサイドドロワーで "画面カラーピッカー" ツールとしても使えます. 画面の内容は端末内でのみ処理されます.

### はじめに

1. ランチャーから 3-Color Picker を開き, "カラーピッカーを開始" をタップします.
2. 表示に従って他のアプリの上への表示を許可し, 続けて今回の画面キャプチャを許可します.
3. 色を取りたいアプリに切り替え, ターゲットリングを目的のピクセルの近くまでドラッグしてから, 拡大鏡の円盤上をスライドして微調整します.
4. リング上の色の値または座標をタップするとコピーされます. リング下部の × をタップすると終了します.

### 主な機能

- **フローティングピッカー**: ターゲットリングで大きく移動し, 拡大鏡には拡大したピクセルグリッド, 現在の色, 座標が表示されます. 拡大鏡の円盤上をスライドすると 1 ピクセルずつ動かせます.
- **色と座標のコピー**: 色の値または座標をタップするとコピーされ, 色の値を長押しすると HEX と RGB が切り替わります. "数値のみをコピー" をオンにすると # と R, G, B の文字を含めずにコピーします.
- **AutoJs6 のサイドドロワー**: AutoJs6 の "プラグインセンター" で本プラグインを有効にすると, サイドドロワーに "画面カラーピッカー" スイッチが表示され, オンで開始, オフで終了します.
- **カラーピッカー設定**: "設定" の "カラーピッカー設定" で "拡大鏡のサイズ", "サンプリング範囲", "微調整の速さ", "グリッド線を表示" を調整できます.
- **外観**: "言語", "ダークモード", "テーマ色" は既定で "AutoJs6 に従う" で, 個別に設定することもできます. "ランチャーアイコン" は複数のスタイルから選べます.
- **動作中の通知**: ピッカーの動作中は通知 "画面カラーピッカーは動作中です" が表示され, 通知から "停止" をタップできます.
- **リリース履歴と謝辞**: "設定" から "リリース履歴" と "デザインの参考と謝辞" も確認できます.

### 動作要件

- Android 7.0 以降. AutoJs6 のサイドドロワーで使うには AutoJs6 6.8.0 以降が必要です. 単独で使う場合は AutoJs6 は不要です.
- 他のアプリの上への表示の権限はフローティングピッカーに使います. 画面キャプチャは開始するたびに Android が確認を求めます.
- 通知の権限は動作状態の表示と "停止" 操作に使います. 拒否してもピッカーは動作します.
- ネットワークは使わず, スクリーンショットも保存しません. クリップボードへの書き込みはコピーをタップしたときだけです.

### よくある質問

**他のアプリの上への表示または画面キャプチャを拒否した場合**

開始は安全に取り消され, オーバーレイは残りません. もう一度 "カラーピッカーを開始" をタップすると, 改めて許可を求めます.

**AutoJs6 のサイドドロワーに "画面カラーピッカー" が表示されない理由**

AutoJs6 の "プラグインセンター" で本プラグインが有効になっているか確認し, 求められた場合は先に承認してください. プラグインセンターで無効にすると, この項目は非表示になります.
