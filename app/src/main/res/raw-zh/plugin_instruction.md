3-Color Picker 是一款屏幕取色工具: 用可拖动的目标环和实时放大镜选中屏幕上任意位置的像素, 然后以 HEX 或 RGB 格式复制颜色和坐标. 可以从启动器单独使用, 也可以在 AutoJs6 侧拉抽屉中作为 "屏幕取色" 工具使用; 屏幕内容只在本机处理.

### 开始使用

1. 从启动器打开 3-Color Picker, 点按 "启动屏幕取色".
2. 按系统提示允许显示在其他应用上层, 再允许本次屏幕捕获.
3. 切换到要取色的应用, 拖动目标环靠近目标像素, 再在放大镜圆盘上滑动微调.
4. 轻点环带上的色值或坐标即可复制; 轻点环带底部的 × 停止取色.

### 主要功能

- **浮动取色器**: 目标环用于大范围移动, 放大镜同步显示放大的像素网格, 当前颜色和坐标; 在放大镜圆盘上滑动可以逐像素微调.
- **复制颜色与坐标**: 轻点色值或坐标即可复制, 长按色值在 HEX 与 RGB 之间切换; 开启 "复制时仅保留数值" 后不带 # 与 R, G, B 字母.
- **AutoJs6 侧拉抽屉**: 在 AutoJs6 "插件中心" 启用本插件后, 侧拉抽屉中会出现 "屏幕取色" 开关, 打开即启动取色器, 关闭即停止.
- **取色设置**: 在 "设置" 的 "取色设置" 中调整 "放大镜大小", "取色范围", "微调速度" 与 "显示网格线".
- **外观**: "语言", "夜间模式" 与 "主题色" 默认 "跟随 AutoJs6", 也可以单独设置; "启动器图标" 有多种样式可选.
- **运行通知**: 取色器运行时通知栏显示 "屏幕取色正在运行", 可以在通知中点按 "停止".
- **发行历史与致谢**: 在 "设置" 中可以查看 "发行历史" 以及 "设计参考与致谢".

### 运行要求

- Android 7.0 或更高版本. 在 AutoJs6 侧拉抽屉中使用需要 AutoJs6 6.8.0 或更高版本, 单独使用不需要 AutoJs6.
- 显示在其他应用上层的权限用于浮动取色界面; 每次启动时 Android 都会请求确认屏幕捕获.
- 通知权限用于显示运行状态与 "停止" 操作; 拒绝后取色器仍可运行.
- 不联网, 不保存截图, 只在你点按复制时写入剪贴板.

### 常见问题

**拒绝显示在其他应用上层或屏幕捕获时的情形**

启动会安全取消, 不会留下浮层. 再次点按 "启动屏幕取色" 即可重新请求授权.

**AutoJs6 侧拉抽屉中没有 "屏幕取色" 的原因**

在 AutoJs6 "插件中心" 确认本插件已启用, 如有提示先授权插件. 在插件中心禁用本插件后, 该条目会隐藏.
